# YODY Design System

Brand identity + production-ready, Tailwind v4 (shadcn-standard) component library for **YODY** — one token foundation across four surfaces (marketing · application · portal · store).

**This repo keeps three docs:**
- **[`DESIGN.md`](./DESIGN.md)** — the design system: brand, tokens, architecture, surfaces, principles, the Tailwind v4 layer, components, and **how to consume it in a real repo**.
- **[`SKILL.md`](./SKILL.md)** — the invocable agent skill (how to generate interfaces with the DS correctly).
- **[`CLAUDE.md`](./CLAUDE.md)** — how to work in this repo + project state/history.

Start with **[`DESIGN.md`](./DESIGN.md)** — or open **[`index.html`](./index.html)** in a browser for a visual intro + hub linking the specimens, examples and docs.

**Consume it:** link **`styles.css`** (the root single-link token entry — it `@import`s `colors_and_type.css`), then add the Tailwind layer / UI kits as needed. See DESIGN.md → "Consuming the design system."
