Kết luận
Bỏ data-surface thì mặc định là portal. Component không bao giờ hard-code cỡ chữ hay gutter — chúng đọc token mà bề mặt phân giải.
Kiến trúc

Ba lớp, từ nền bất biến đến component.

I

Foundation — token nền

Màu thương hiệu, accent ngữ nghĩa, palette trạng thái, họ chữ, easing, sàn a11y. Sống trong :root của colors_and_type.css. Phổ quát, không bao giờ bị bề mặt ghi đè.

II

Surface adapters — bốn bộ tỷ lệ

Mỗi [data-surface="…"] phân giải tỷ lệ riêng: type-size, gutter, row-height, motion-budget, accent-freq. Chỉ token tỷ lệ thay đổi theo bề mặt.

III

UI kits — component tổ hợp

Khối dựng sẵn theo nhu cầu: yody-app, yody-ai, yody-collab (cross-product) và yody-fashion (theo ngành). Tiêu thụ token từ adapter, không định nghĩa lại nền.

Bắt đầu nhanh

Dựng một màn hình YODY trong vài phút.

Quy tắc vàng: luôn nạp token trước, đặt data-surface, rồi mới tới lớp component. Đủ để một frontend dev bắt đầu mà chưa cần đọc hết DESIGN.md.

I

Nạp token nền

colors_and_type.css — bắt buộc, luôn đầu tiên. Chứa toàn bộ biến màu, chữ, spacing, motion và sàn a11y.

II

Đặt data-surface

Trên <body> hoặc container: marketing · app · portal · store. Thiếu nó = mặc định portal. Component đọc tỷ lệ từ đây.

III

Chọn lớp component

React → cài qua shadcn @yody/*. Không React → nạp lớp Tailwind + ui_kits/* rồi dùng class ngữ nghĩa.

React

Vite / Next + Tailwind v4

Nạp token + theme một lần ở entry, rồi cài component. Item upstream tự lên màu YODY vì theme đã map role token.

// 1 · entry (main.tsx) — nạp một lần, đúng thứ tự
import "./colors_and_type.css";  // token nền
import "./globals.css";          // role token + .dark

# 2 · trỏ shadcn vào registry @yody (components.json)
"registries": { "@yody": "https://HOST/r/{name}.json" }

# 3 · cài component — namespace, URL, hoặc upstream
npx shadcn add @yody/button @yody/select
npx shadcn add tooltip popover   # tự brand
Non-React

Server-render · HTML · Vue

Nạp token → lớp Tailwind → ui_kits/* (khi cần). Rồi dùng class ngữ nghĩa hoặc role/utility trực tiếp.

<!-- thứ tự nạp cố định -->
<link rel="stylesheet" href="colors_and_type.css">
<link rel="stylesheet" href="tailwind/yody.components.css">
<link rel="stylesheet" href="ui_kits/yody-app/index.css">

<body data-surface="app">
  <button class="btn btn-primary">Lưu</button>
  <span class="tag tag-live">LIVE</span>
</body>
Token hay dùng
  • Nền/CTA: bg-primary · bg-brand
  • Chữ: text-foreground · text-muted-foreground
  • Accent: --iris --gold --mint --rose
  • Type: text-h1 … text-body text-eyebrow
Dùng UI kit nào?
  • yody-app — shell, table, filter, chart
  • yody-ai — composer, halo, confidence, panel
  • yody-collab — comment, approval, presence
  • yody-fashion — swatch, BOM, size matrix
Đừng quên
  • Token, không hard-code hex
  • data-surface đúng ngữ cảnh
  • Type scale, không text-[Npx]
  • Focus ring + vùng chạm ≥ 44px

Tham chiếu đầy đủ: DESIGN.md · skill agent SKILL.md · specimen sống trong preview/ · component cài được trong public/r/.

Quy tắc bất di bất dịch

Sáu điều giữ bốn bề mặt thành một thương hiệu.

1

Khai báo data-surface

marketing · app · portal · store. Thiếu = tỷ lệ portal.

2

Dùng token, không dùng hex thô

Màu, cỡ chữ, gutter đều đọc từ biến — không phát minh màu mới.

3

Gold chỉ để trang trí

Logo, một điểm nhấn/trang. Không bao giờ chữ hay nút màu gold.

4

Không emoji

Trạng thái thể hiện bằng tag pill (LIVE / BUILD / GAP / PLAN).

5

Viết thường (sentence case)

Không chấm than, không sáo ngữ. Ưu tiên tiếng Việt, giữ thuật ngữ tech tiếng Anh.

6

Sàn a11y

Focus ring rõ, tap target ≥ 44px (56–72px ở store), tôn trọng reduce-motion.
